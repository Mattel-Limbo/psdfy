# psdfy

PSD layer converter and processor.

## Installation

```bash
pip install -e .
```

## Usage

```bash
psdfy --help
```

## Development

Install development dependencies:

```bash
pip install -e ".[dev]"
```

Run linting:

```bash
ruff check .
black --check .
```

Format code:

```bash
black .
ruff check --fix .
```
